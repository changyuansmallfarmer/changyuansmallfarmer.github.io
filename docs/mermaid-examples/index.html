Mermaid 图表示例

本文档展示了如何在 Docusaurus 中使用 Mermaid 图表。Docusaurus 会自动将 Mermaid 代码块渲染为 SVG 格式的静态图表。

流程图​

graph TD
    A[开始] --> B{是否有问题?}
    B -->|是| C[解决问题]
    B -->|否| D[继续前进]
    C --> D
    D --> E[结束]

时序图​

sequenceDiagram
    participant A as 用户
    participant B as 系统
    participant C as 数据库

    A->>B: 发送请求
    B->>C: 查询数据
    C-->>B: 返回结果
    B-->>A: 响应数据

状态图​

stateDiagram-v2
    [*] --> 未开始
    未开始 --> 进行中: 开始任务
    进行中 --> 已完成: 完成任务
    进行中 --> 已取消: 取消任务
    已完成 --> [*]
    已取消 --> [*]

类图​

classDiagram
    class Animal {
        +String name
        +int age
        +eat()
        +sleep()
    }
    class Dog {
        +bark()
        +fetch()
    }
    class Cat {
        +meow()
        +climb()
    }
    Animal <|-- Dog
    Animal <|-- Cat

甘特图​

gantt
    title 项目进度安排
    dateFormat  YYYY-MM-DD
    section 设计阶段
    需求分析       :a1, 2024-01-01, 7d
    系统设计       :a2, after a1, 5d
    section 开发阶段
    前端开发       :b1, after a2, 10d
    后端开发       :b2, after a2, 12d
    section 测试阶段
    单元测试       :c1, after b1, 3d
    集成测试       :c2, after b2, 5d

饼图​

pie title 技术栈分布
    "React" : 40
    "TypeScript" : 25
    "Node.js" : 20
    "其他" : 15

ER 图（实体关系图）​

erDiagram
    CUSTOMER ||--o{ ORDER : places
    ORDER ||--|{ LINE-ITEM : contains
    CUSTOMER }|..|{ DELIVERY-ADDRESS : uses

    CUSTOMER {
        string name
        string email
        string phone
    }
    ORDER {
        int id PK
        date order_date
        string status
    }
    LINE-ITEM {
        int id PK
        int quantity
        float price
    }
    DELIVERY-ADDRESS {
        string street
        string city
        string zip_code
    }

C4 上下文图​

C4Context
    title 系统上下文图
    Person(user, "用户", "使用系统的用户")
    System(web_app, "Web 应用", "用户访问的主应用")
    System_Ext(email_service, "邮件服务", "第三方邮件发送服务")
    Rel(user, web_app, "使用")
    Rel(web_app, email_service, "发送邮件")

复杂流程图​

graph LR
    A[开始] --> B{判断条件}
    B -->|条件1| C[处理1]
    B -->|条件2| D[处理2]
    B -->|条件3| E[处理3]
    C --> F{检查}
    D --> F
    E --> F
    F -->|通过| G[成功]
    F -->|失败| H[重试]
    H --> B
    G --> I[结束]

总结​

本页面展示了各种 Mermaid 图表类型。所有图表在构建时自动生成为 PNG 图片，提高了页面加载性能和兼容性。
