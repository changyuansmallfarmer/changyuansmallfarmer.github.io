  • 查看内存管理区的信息

/proc/zoneinfo节点包含当前系统所有内存管理区的信息。/proc/zoneinfo节点显示如下几部分信息。

1．当前内存节点的内存统计信息下面是/proc/zoneinfo节点的第一部分信息。

</proc/zoneinfo节点的第一部分信息>
Node 0, zone    DMA32
  per-node stats
      nr_inactive_anon 6196
      nr_active_anon 198700
      nr_inactive_file 183190
      nr_active_file 36479
      nr_unevictable 12
      nr_slab_reclaimable 13164
      nr_slab_unreclaimable 20420
        ....
         nr_kernel_misc_reclaimable 0

在第2行中，表示当前内存节点是第0个内存节点，当前内存管理区为DMA32。

在第3行中，表示下面是该内存节点的总体信息。如果当前内存管理区是内存节点的第一个内存管理区，那么会显示该内存节点的总信息。它通过node_page_state()函数来读取内存节点的数据结构pglist_data中的vm_stat计数值。

上述信息是在zoneinfo_show_print()函数中输出的。

<mm/vmstat.c>

static void zoneinfo_show_print(struct seq_file *m, pg_data_t *pgdat,
                            struct zone *zone)

2．当前内存管理区的总信息

下面继续看/proc/zoneinfo节点的信息。

</proc/zoneinfo节点的第二部分信息>

  pages free     352843
        min      2023
        low      2528
        high     3033
        spanned  524288
        present  507904
        managed  353134
        protection: (0, 6002, 6002)

pages free：表示这个内存管理区中空闲页面的数量。

min：表示这个内存管理区中处于最低警戒水位的页面数量。

low：表示这个内存管理区中处于低水位的页面数量。

high：表示这个内存管理区中处于高水位的页面数量。

spanned：表示这个内存管理区包含的页面数量。

present：表示这个内存管理区里实际管理的页面数量。

managed：表示这个内存管理区中被伙伴系统管理的页面数量。

protection：表示这个内存管理区预留的内存（lowmem_reserve）。

3．内存管理区详细的页面信息

接下来是内存管理区详细的页面信息。

</proc/zoneinfo节点的第三部分信息>

     nr_free_pages 352843
      nr_zone_inactive_anon 0
      nr_zone_active_anon 0
      nr_zone_inactive_file 0
      nr_zone_active_file 0
      nr_zone_unevictable 0
      nr_zone_write_pending 0
      nr_mlock     0
      nr_page_table_pages 0
      nr_kernel_stack 0
      nr_bounce    0
      nr_zspages   0
      nr_free_cma  7911
      numa_hit     41
      numa_miss    0
      numa_foreign 0
      numa_interleave 0
      numa_local   41
      numa_other   0

上述是这个内存管理区详细的页面信息。它通过zone_page_state()函数来读取zone数据结构中的vm_stat计数值。

4．每个CPU内存分配器的信息

最后是每个CPU内存分配器的信息。

</proc/zoneinfo节点的第四部分信息>

  pagesets
    cpu: 0
              count: 0
              high:  378
              batch: 63
  vm stats threshold: 30
    cpu: 1
              count: 0
              high:  378
              batch: 63
  vm stats threshold: 30
    cpu: 2
              count: 0
              high:  378
              batch: 63
  vm stats threshold: 30
    cpu: 3
              count: 0
              high:  378
              batch: 63
  vm stats threshold: 30
  node_unreclaimable:  0
  start_pfn:           524288

pagesets：表示每个CPU内存分配器中每个CPU缓存的页面信息。

node_unreclaimable：表示页面回收失败的次数。

start_pfn：表示内存管理区的起始页帧号。
