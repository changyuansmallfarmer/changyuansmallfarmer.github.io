农村孩子的婚姻观为什么跟父母不一样了？

这里先介绍下背景：我老家是河南很普通的一个农村，村里人没有挣钱的门路。男的大多数都是去传说中的工地搬砖，是真正的体力活，又脏又累那种；女的大多数要不去南方电子厂，要不就是在老家县城找个活干，过几年到了适婚的年纪就回家相亲结婚，结完婚后男的外出打工，女的在家做全职太太。

这里先聊下我父母的婚姻，他们1970年左右出生，当时虽然不至于饿着，但是也还没过上每顿都能吃上白面馒头的地步。我爸小学没上完就毕业了，刚十五六岁就跟着村里的人走南闯北的在工地上干活，那个年代是制度还不健全，有很多造假证的，所以我爸才能在各个工地干活；当然了，一个没学历没背景的农村穷小子在工地上干的都是最苦最累的活。

等到我爸到了适婚的年龄，我爷爷奶奶就托人给我爸介绍对象相亲，我也不知道我爸相了几个，因为他也从来没说过这些，都是我妈告诉我的，相亲成功的对象肯定是我妈了，要不然我也不会在这里写文章给大家看。

他们俩就见了两面就订婚了，第一面是在我姥姥家，媒人带着我爷爷奶奶和我爸过去的，我爸个子挺高的，我姥姥在见面之前也打听了我爸这边的家庭情况，就同意了；第二次见面是第一次见面不久，我们镇上有集会，我爸就带着我妈赶集去了，赶集这个词可能现在大家了解得不多，相当于现在得逛街，赶集的时候我爸饿了，就自己买了个火烧吃，也没给我妈买，就这件事被我妈说了二三十年了，即使这样他们俩还是把婚事订了下来，订完婚后不久我爸就外出打工了，当时也没有电话，过了将近一年没有联系，等我爸回到老家，两个人就结婚了。

那个年代的婚姻属于让男女双方物质上1+1>2，这也跟当时的大环境相关，农村的人刚能够温饱，家里找对象就要求踏实有膀子力气就行，毕竟那个时代给提供的工作岗位大部分都是只有男人才能干的体力活，给女人提供的工作岗位要少很多，成家之后绝大多数女人就会成为家庭主妇，我记得我小时候一年见不了我爸几天，因为他要外出打工养活这一大家子。

接着聊下农村90后的婚姻，

23年过年的时候回家见到了自己发小们，他们大多数都在十七八岁的时候结婚了，那时候家里能在宅基地盖三间房子，几千块钱的彩礼就可以把媳妇娶回家了，他们跟我们的父辈一样，每年在工地上呆个10个月左右，然后剩余的一两个月就在在家吃喝玩乐，这个风气是父辈传下来的，孩子只不过是跟着学而已。

我92年出生，我们村里跟我相差2岁左右的孩子大概有150人左右，最后上完学就是大专以上的人也就我们六七个人，所以父母永远是孩子的榜样。

这里聊一下我一个未结婚发小的事情，他比我早出生一周，不过他初中没上完就不上了，然后呢从初中开始就是那种酷酷的男生，特别喜欢韩系风，

二十露头的时候，就留了类似韩国男明星的长头发，可是在农村其实很多家长和女孩本人接受不了这种发型，也聊了好多个，感觉那时候他觉得农村的女孩都比较土，但是不土的好像也没相中他，反正最终都没有聊成。过年回家见他的时候，已经绑上了小辫子，越来越有艺术气息了，唯一可惜的是，这么过年过去了，农村依旧接受不了这样，他也就单身到了现在。

跟他聊感觉其实他也很想结婚，之前聊的要不颜值不符合他的要求，要不聊不到一起，要不因为彩礼之类的聊崩了，反正就是各种原因吧。

随着年龄的增长，跟他年龄相匹配的女孩在农村也越来越少，匹配的也都是离婚带娃的这种，加上现在农村的彩礼越来越高，我也不知道他还能不能遇到他心里的那个她，我还是衷心希望他能找到的，虽然有点小毛病，但是整体是一个有担当的男人。

接下来聊聊我的堂妹。我堂妹也在农村长大，大学毕业后，通过考教师资格证，然后考教师编，现在在我们旁边县的一个镇中学当老师。

过年的时候也跟她聊了下，也很无奈，她94年生，跟我媳妇一样大，今年也都三十了。按理说农村由于当年计划生育的政策，男孩比例要大于女孩的比例，应该也好找老公的，况且还有教师编。

这个问题我也根据我了解的情况简单说下，首先说下个人观点，女孩一般很少会降低自己的期望标准的，比如我堂妹是个本科，她能接受的底线估计也就是大专了，不然农村很多初中没上完的男孩，她早就结婚了。

从我身边以及包括我自己，上学的男孩有两条路，这两条路也不是自己想怎么选就怎么选的，是根据家里的经济条件决定的，举个例子吧，我家里没办法在县城给我买房买车，我就大学毕业就来到了北京工作，因为北京工作机会多，工资高。我一个高中同学，大学毕业后家里帮忙在县城买了房和车，自己也考上了教师编，一周也上不了几天班，还有寒暑假，所以刚毕业两年二十五六就结婚了，到现在孩子都两个了，而我是去年结的婚，结婚的时候三十一岁。

现实版本的族望留原籍，家贫走他乡。

农村上过学的女孩一般会怎么选呢？不管家里条件好不好她们大多数都会选择回家考个教师编、事业编、银行编之类的，因为在我们那边截至目前结婚都是男孩买房买车，所以女孩没有经济压力，加上离家近，所以都会这么选择。

这就会造成一个问题，上过学的跟我妹差不多的男孩，到了30岁这个年龄，要不就是早就结过婚了，要不就像我这也漂泊在外也很少会回去的，也不会选择在家里找一个媳妇，两地分居，在漂泊的城市找一个一起漂泊的人不是更好抱团取暖吗？

其实婚姻的本质就三个方面：1、让男女双方物质上1+1>2 2、让男女双方精神上1+1>2 3、繁衍下一代
