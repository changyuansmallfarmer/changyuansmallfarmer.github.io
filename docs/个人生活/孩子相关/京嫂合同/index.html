第三条服务内容

乙方为甲方提供母婴护理服务的工作内容为：

（1）协助甲方到医疗机构完成新生儿医疗咨询、诊治和预防接种。

（2）生活护理：协助甲方营造产后良好的休养环境，做好室内通风，保持室内卫生，帮助产妇做好个人清洁卫生工作。

（3）根据产妇身体状况、乳汁分泌情况，制作月子期间的产妇营养餐、协助产妇做产后恢复训练。

（4）针对侧切或剖宫产伤口的护理，观察和处理恶露，会阴护理。

（5）乳房基础护理：清洁乳头，处理乳头内陷、乳头皲裂，按摩护理，缓解乳房胀痛。

（6）指导产妇保持正确的哺乳姿势，在母乳哺乳开始前提醒或协助产妇清洗乳头。

（7）根据甲方的要求，与产妇交流，进行心理沟通与心理辅导，预防或缓解产后忧郁。

（8）正确判断新生儿哭闹的原因，识别新生儿正常与异常状况。

（9）根据产妇与新生儿的实际情况，指导母乳喂养、人工喂养或混合喂养。

（10）为新生儿换尿布、洗澡、脱穿衣服，洗涤与消毒衣物、奶瓶和日常用品。

（11）为新生儿眼、耳、鼻和头部进行日常清洁护理，发现并处理异常分泌物。

（12）对新生儿臀部与脐带进行日常护理。

（13）及时发现新生儿腹泻、呕吐、发热、惊厥等症状，向甲方反馈。

（14）引导新生儿良好的生理习惯，为新生儿抚触、锻炼四肢协调能力。

（15）根据甲方的要求，开发新生儿感觉、知觉和互动的能力。

（16）新生儿的安全：及时发现影响新生儿安全的因素，预防窒息、跌伤、烫伤等伤害事故。

（17）母婴护理师负责产妇月子餐以及宝宝的喂养，在工作条件允许的情况下可以辅助做家庭餐，但家庭成员需确保宝宝的安全和照顾。

（18）指导产妇在月子期结束后基本掌握婴儿洗澡和日常护理等基本技能。

（19）卫生区域打扫：厨房卫生打扫、月子房卫生打扫及母婴护理师和宝贝居住房卫生打扫，在工作条件允许的情况下可以辅助卫生间和客厅卫生，但家庭成员需确保宝宝的安全和照顾。

第四条服务场所及人员更换

1、在合同期内，若乙方由于自身原因无法继续为甲方提供服务，丙方无条件推荐同级别的母婴护理师供甲方筛选使用。

2、在合同期内，若乙方的工作出现疏漏、过失或造成损失的，甲方有权要求丙方推荐新的母婴护理师，推荐工作需按照以下方式处理：

（1）甲方需当天以微信或电话的形式通知丙方工作人员，丙方需在2-3日内为甲方推荐同级别的母婴护理师供甲方筛选。

（2）若甲方无法提前通知丙方而径自要求乙方下户的，甲方需通知丙方。丙方需在2-3日内，为甲方推荐新的母婴护理师，并签署新的合同。服务费以实际服务发生日数为准。

第八条乙方的权利和义务

（1）乙方享有获得劳动安全卫生保护的权利，如甲方工作环境存在安全隐患、卫生条件恶劣或有强令冒险作业等因素，乙方有权拒绝执行。如因甲方原因造成乙方人身或其他权益受侵害的，乙方有权要求甲方承担相应法律责任。

（2）乙方有权得到服务报酬。乙方有权拒绝甲方增加合同规定之外的服务项目，如双方协商同意，乙方有权要求甲方支付相应的报酬。

（3）乙方应提供必要的有效证件，如健康证、身份证、培训证书等。如甲方要求乙方重新体检，体检结果合格费用由甲方承担。体检不合格费用由乙方承担。

（4）乙方必须遵守国家的法律法规，按合同约定服务。不得有损害甲方合法权益的行为，如乙方因过错而造成甲方人身或其他权益受侵害的，则要承担相应的法律赔偿责任。

八、特别提醒：以下各条必须请客户一定认真阅读，并加以确认（母婴顾问需向客户逐条说明）：

1、关于疾病判断：由于乙方属于非医护人员，对婴幼儿疾病无法正确地判断和鉴定，也无法及时提醒甲方。所以甲方作为宝宝监护人，也一定要多留心、多观察、多询问宝宝状况。分娩后宝贝如果有疾病，甲方一定要如实告知乙方和丙方，提供出院小结，提前做好有关准备。如甲方未及时告知宝贝和宝妈的特殊情况，由此产生了护理失误等，由甲方自行负责。

2、关于甲方要求乙方单独体检:乙方在上户前需向甲方提供医院或体检中心出具的真实有效的体检报告。乙方未经甲方确认身体状况和体检报告，严禁入户服务。

3、关于新生儿尿路感染:甲方应该特别重视婴幼儿尿路感染问题，这是常发疾病。实践证明，婴幼儿尿路感染发生的原因很多，并非只是护理不当导致（保险公司对疾病不予赔偿）。所以请甲方密切关注婴幼儿清洁问题并及时检查月嫂对婴儿臀部的清洁状况是否合格。如果甲方不检查或者检查不严格，一旦发生婴幼儿尿路感染问题，将不能要求对乙方进行处罚和赔偿。

4、关于新生儿肺炎：宝宝吐泡泡等，有可能是肺炎的前兆，要十分重视，及时就医。宝宝呛奶急救流程和措施，家属也必须学会，万一乙方不在现场或已经服务结束，作为宝宝照护人员都需要掌握这一技能。

5、关于新生儿防摔：新生儿防摔是新生儿护理的重中之重，甲方和乙方必须高度重视，尤其在夜间奶后拍嗝或哄睡等环节特别容易滑落和摔伤。所以必须重视以下几点:

1）严格预防乙方瞌睡时抱孩子，防止滑落和摔伤

2）在相对固定的位置进行喂奶、拍嗝或哄睡。

3）尤其是夜间喂奶拍嗝哄睡时，必须采取防护措施，如在地板上铺垫被子、褥子或垫子等足以可以减轻对宝贝造成伤害的防摔措施，如无保护措施不得作业。

4）宝贝玩耍或睡觉时，应放在距离床40厘米以外的位置。
