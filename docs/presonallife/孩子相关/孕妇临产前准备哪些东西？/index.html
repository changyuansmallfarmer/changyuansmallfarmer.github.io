一，孕妇用品

脸盆、毛巾、牙刷、肥皂、香皂、洗衣粉等洗漱用品，这些都是住院的一些日常需要。还要准备一些高热量的食物，补充孕妇分娩时的能量，可以带一些巧克力。水杯，最好准备一个大一点的保温壶。孕妇产后不能着凉，可以喝点温水。还要准备一些卫生巾和卫生纸。产后会有大量XX排出。这个时候最好准备一些成人纸尿裤，对产妇来说会更方便。红糖可以快速补血，特别是对于刚生完孩子的产妇。

二，婴儿用品

宝宝的包，衣服，床上用品，尿布，尿不湿，沐浴露，发酵粉，湿巾，纸巾，口水巾，毛巾。宝宝的衣服可以多拿几件，方便宝宝换洗，因为产后要在医院观察几天。这个时候要给宝宝带够东西，宝宝的被褥要根据天气来选择。

三、孕妇分娩应该准备什么？

当产妇准备入院分娩时，袋子是必不可少的，主要集中在母亲的物品上。要提前准备好要送的物资，而不是临时抱佛脚，避免不必要的仓促。为了更全面的准备要送的货，最好提前咨询医院或者有经验的妈妈。首先，衣服。选择透气、吸水、柔软的面料，系带的和尚服是最好的款式。刚出生的宝宝因为奶水过多或者排泄物弄脏了衣服，需要随时更换内衣，所以至少要给宝宝准备3件。另外，最好准备点小衣服，边穿边买，因为宝宝长得快，穿起来就够了。其次是生活用品:洗漱用品，带前扣的换洗衣服，梳子，乳液，拖鞋，保温杯，保暖衣服，还有相关证件:医保卡，身份证，妈妈手册。可以选择前开式或者吊带开式，方便给宝宝喂奶，准备住院时可以更换。另外，带好必要的卫生巾，因为产后私处易受细菌感染或湿疹，一定要保持干爽清洁；选择安全正规的产妇卫生巾，提前去正规商场购买。总之，如果有时间，可以多花点时间准备，但是缺的东西可以及时补上。准备去接贝比。这个时期会很刺激，因为我们要去看宝宝了，也因为怀孕快结束了，不知道为什么经常会回忆起从知道怀孕的那一刻到后来怀孕的全过程。我想这是很多妈妈永远不会忘记的甜蜜回忆吧！
